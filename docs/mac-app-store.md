## Description

Compare Amazon.com search results by what you actually get for the price. The Safari extension adds “Price per oz/count” to the Sort by menu on Amazon.com search results.

Choose that option to reorder the results currently loaded on the page by unit price. Each eligible product gets a badge showing the unit price used. When Amazon's displayed unit price conflicts with the size or pack quantity in a product title, the extension recalculates it and marks the badge with an asterisk.

Products priced per ounce appear first, followed by products priced per count, other units, and products without a usable unit price. The extension can sort only products Amazon has loaded on the current page.

The extension runs only on Amazon.com search result pages. It has no account, analytics, or data collection. Independent extension; not affiliated with Amazon.

## App Review notes

Open the app and use its button to open Safari Extensions settings. Enable “Amazon Results Sort by CostPerCount” and allow it on Amazon.com. Search Amazon.com for coffee beans, then select “Price per oz/count” in the Sort by menu. The page will show the selected sort and unit-price badges. No login or test account is required to use the extension.
