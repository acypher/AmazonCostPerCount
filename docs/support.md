# Amazon Results Sort by CostPerCount Support

This extension adds **Price per oz/count** to the Sort by menu on Amazon.com search results. It sorts only products loaded on the current page.

If the option or price badges are missing, refresh the Amazon search page. If a price looks wrong, send the product title, displayed price, browser, and steps to reproduce to [code@acypher.com](mailto:code@acypher.com). Do not send account or payment information.
